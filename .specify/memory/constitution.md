# PetStore Constitution

## Core Principles

### E-commerce Platform
The application is a fullstack e-commerce platform dedicated to selling pets such as dogs, cats, birds, and fishes. All features must align with facilitating pet sales, inventory management, and customer interactions.

### Technology Stack
Backend implemented using Java Spring Boot, database using Postgres, containerized with Docker. Frontend using React, styled with Tailwind CSS and Material-UI (MUI).

### API and Package Naming
All API paths and Java packages must incorporate the surname "natividad" for consistency and branding.

### Deployment Strategy
The application will be deployed on Render using free-tier services, ensuring cost-effective and scalable hosting.

### Security and Best Practices
Implement secure payment processing, data protection for user and pet information, and follow best practices for e-commerce applications.

## Additional Constraints
- Use free-tier limitations of Render for deployment.
- Ensure the application is responsive and accessible.

## Development Workflow
- Follow agile development practices.
- Code reviews required for all changes.
- Automated testing for backend and frontend.

## Governance
Constitution governs all development. Amendments require consensus and documentation.
